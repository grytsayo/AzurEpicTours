# Недельные туры

Публичная страница: `/weekly-tours`, языки RU / EN / FR. Общий с остальным сайтом ключ языка `selectedLanguage`. На главной — отдельный блок пакетных путешествий, вне карточек обычных экскурсий и их условий отмены.

## Управление

Откройте `/weekly-tours-admin`. Для входа используется существующий `REVIEW_ADMIN_TOKEN`; отдельный `WEEKLY_TOURS_ADMIN_TOKEN`, если задан в окружении Netlify Functions, имеет приоритет. Токен не сохраняется в localStorage и не включён в HTML/JS. Страница закрыта от индексации, API проверяет токен на сервере и origin при сохранении.

В карточке заезда можно менять начало и окончание, вместимость, свободные места, цену на человека, статус и публикацию. При изменении начала окончание автоматически устанавливается на шестой день. Нажмите «Сохранить и опубликовать». Изменения сохраняются в Netlify Blobs (`weekly-tours`, ключ `schedule`) и доступны при обновлении публичной страницы без Git deploy. Ошибки загрузки не маскируются стартовыми данными. Сохранение использует ETag и условную запись, чтобы другая вкладка не затёрла свежие изменения.

Стартовые данные, согласованные владельцем: 11–16, 18–23 и 25–30 марта 2027; вместимость и свободные места — по 6, цена 1200 EUR за человека. Статус «Набор группы». Они используются только пока запись schedule ещё не создана. После первого сохранения источником становится Blobs, в том числе если список сохранён пустым. Прошедшие по дате начала (часовой пояс Парижа), отменённые и неопубликованные заезды не показываются посетителям.

Остаток 0 включает лист ожидания, пустой остаток — наличие по запросу. Статус проведения независим от числа мест. Места не списываются автоматически.

## Обращения

Посетитель выбирает заезд и количество участников, затем WhatsApp или email. Открывается приложение с готовым текстом на выбранном языке: гость должен сам отправить сообщение. WhatsApp и email взяты с действующего сайта. Персональные данные не собираются и не сохраняются этой страницей. Обращение не резервирует место; владелец лично согласует участие и меняет остаток в кабинете. Календарь обычных экскурсий и Vercel API не задействованы.

## Проверка

`node scripts/test-weekly-tours.mjs` запускает локальный официальный эмулятор Netlify Blobs. Проверяются сохранение и чтение, ETag-конфликты, валидация, токен, origin, скрытые/прошедшие/отменённые заезды и совместимость отзывов с обновлённым клиентом Blobs. Данные теста хранятся во временной папке и удаляются после проверки. Production-записи и сообщения не создаются.

Проверить браузером: RU / EN / FR, переход с главной с сохранением языка, все три даты, ноль мест/лист ожидания, контакты без отправки, мобильные ширины, кабинет. Публикация только push origin main. Локальные drafts не коммитить; production дополнительно блокирует `/drafts/*`.
